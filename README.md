## 📁 目录约定

每个话题一个**自包含文件夹**：

```
agents/<topic>/
├── report.md        # Markdown 源文件
├── report.html      # 暗色精排版（含目录、图表）
├── README.md        # 本话题报告摘要
├── diagrams/        # 架构图源文件
└── fonts/           # 报告内嵌字体（按需）
```
