## 📝 文档规范
1. 新增文档先编写Markdown源文件放到对应分类的`markdown/`目录下
2. 使用markdown-to-html工具转换为HTML文件放到对应分类的`html/`目录下，默认使用`academic`学术风格
3. 技术调研文档统一包含：问题背景、核心分析、关键技术点和结论、落地方案、注意事项、参考资料六个部分
4. 文档命名采用中文名称，清晰说明文档主题
5. 禁止上传敏感信息、内部数据、密钥等内容
