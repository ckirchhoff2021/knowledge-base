OPD 训练流水线：学生采样 → 教师打分 → 逐 token 更新

学生 πθ 在自己采样的轨迹上，由教师 ν 在每个前缀给出 next-token 分布，按 reverse-KL / 策略梯度更新

关键设计

  • • 学生负责走到自己真实会遇到的状态
  • • 教师负责评价"这一步走得对不对"
  • • on-policy 采样协议 + KL/PG 优化协议分离

监督密度

  • • 1000-token 轨迹 → 数百~上千个 next-token 信号
  • • 教师分布含风格、不确定性、多路径信息
  • • 比 RL 的序列级标量奖励稠密得多

实现要点

  • • 在带 KL 正则的 RL 脚本上改一行即可
  • • 正则的 reference model 换成 teacher
  • • 复用 PPO/GRPO 的 rollout 与 importance sampling
