后训练范式定位：采样来源 × 监督密度

OPD = RL 的 on-policy 相关性 + 蒸馏的 dense 监督；OPSD 将教师替换为"持有特权信息的自己"

SFT / Off-Policy KD

  • • 稠密逐 token 监督，但训练状态来自外部数据
  • • 推理时学生访问自己生成的前缀 → exposure bias
  • • 上限受教师轨迹锁死，教师错则学生跟着错

RL / RLVR

  • • on-policy 采样，学生直面自己的错误
  • • 每回合固定信息量，与 token 数无关（稀疏）
  • • 只知道"答错了"，不知道"错在哪一步"

OPD / OPSD

  • • 学生采样 + 教师逐 token 分布 = 稠密且 on-policy
  • • 1000-token 轨迹可产生上千个 next-token 信号
  • • OPSD 用"带答案的自己"当老师，免外部教师
