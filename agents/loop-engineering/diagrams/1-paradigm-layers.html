🔁 Loop Engineering（外环 / outer loop）构建在 Harness 之上

  • 触发 → 装载状态 → 派活 → 独立验证 → 判停 / 升级 → 落盘 → 下一轮
  • 记忆在磁盘（progress.md / 看板 / git），跨会话存活
  • 解决：人工验收、跨任务调度、"下一轮还踩不踩同一个坑"

不是 while 循环

普通循环没有判断能力；Loop Engineering 的关键是独立验证 + 显式停止条件，不是让模型傻跑。

不是 Prompt 已死

循环内每次模型调用仍靠 prompt、上下文与工具描述；变化的是杠杆点向外移动。

不是越自动越好

从回合制起步，按自治度阶梯升级；无刹车的 Agent 不是自动化，是成本风险。
