Andrew Ng《Three Key Loops for Building Great Software》· The Batch 2026-06-26

🌍 ③ 外部反馈循环 External Feedback Loop

小时 ～ 天 / 周级
朋友反馈、alpha 测试、生产环境 A/B 测试——最慢的环，数据反向塑造产品愿景。工程师开始部分承担产品经理角色。

🧭 ② 开发者反馈循环 Developer Feedback Loop

几十分钟 ～ 小时级
开发者审查当前产品、引导 Agent 改进。随着 Agent 自测能力增强，开发者从"给 Agent 当 QA 手动找 bug"解放，转向功能取舍、UI、用户流等高层产品决策。

⚙️ ① 智能体编码循环 Agentic Coding Loop

分钟级
给定产品规格（+ 可选 evals 评估集），Agent 写码 → 测试 → 修 bug → 再测，直到无 bug 且满足规格。可连续自主工作约 1 小时并用浏览器多次自检（Ng 亲述案例）。

三个速度同时运转

内层几分钟一圈、中层几十分钟、外层天/周；彼此嵌套、彼此驱动，像三个同心齿轮。

building 与 feedback 平衡

把愿景翻译成规格是重活，但只埋头 building 不拿外部反馈，愿景无法演化——两者都要做。

对应 Loop Engineering

内环 = turn/goal 循环；开发者环 = human on the loop；外部环决定 proactive 循环该去监听哪些事件。
