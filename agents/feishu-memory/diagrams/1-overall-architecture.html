飞书数字员工记忆系统总体架构：五层记忆 × 四级隔离 × 双通道写入

参照 Hermes Agent 三层记忆（有界常驻 + 按需检索）与 Claude Tag 分层隔离（向下继承、不向上泄漏）· 虚线 = 治理 / 常驻注入路径

分层蒸馏：存什么、何时存

  • • 短期消息不直接复制进长期记忆——必须经 LLM 蒸馏（提取-消解-时效）
  • • 热路径：用户主动沉淀（最高置信）+ 任务结果回写，即时生效
  • • 冷路径：观察消息流后台批处理，粗筛砍 80% 噪声再精炼

隔离与检索：怎么取

  • • 四级 scope（员工/群/单聊/会话），向下继承、不向上泄漏
  • • 检索强制带范围约束，代码层禁止无隔离回退
  • • memory-as-a-tool 按需召回，注入预算 ≤4K token、延迟 ≤500ms

治理：忘得掉、改得动

  • • 旧事实不删除、标失效（双时间字段），回答"现在以哪个版本为准"
  • • 画像有界硬上限，写满强制整理；使用衰减定期归档
  • • 写入安全扫描 + 待审求证，防记忆投毒与个人发言冒充共识
