HAT：Harness-State Augmentation 与三阶段训练

TaoLive 数字人（arXiv:2608.15763）：任务保持型扰动，让小模型「理解 Harness」而不是背版本
HSA 五维扰动（语义不变，专破捷径）

Skill 标识符

注入合成/噪声技能、屏蔽、重命名、强模型重写描述

破解：靠固定技能 ID 路由

Skill 内容

规则改写、随机屏蔽、重新排序

破解：靠规则位置与措辞

工具定义

工具重命名、描述重写（功能不变）

破解：靠工具名匹配

System Prompt

块/条目重排、数值约束合法扰动（长度、轮数）

破解：只认熟悉模板

Hook

重试行为、消息结构、Hook 触发修正的受控变体

破解：记死重试模式
三阶段训练流水线
STAGE 1

HSA-SFT

  • 教师强模型在原始+增强 Harness 下生成轨迹
  • 按 Accuracy+Effectiveness 过滤（~10K 真实直播样本）
  • retry 轨迹：多数只留最终正确行为，少量留完整重试学恢复
➜
STAGE 2

General On-Policy Distillation

  • 生产级实时流模拟器中 on-policy 采样
  • 恢复 SFT 损失的通用能力（防 IFEval 回退）
  • 注入受控故障训练错误恢复

模拟器四组件

直播流输入咨询/闲聊/购买/售后弹幕 + 房间状态
Harness 调度Skill 路由 / Hook 检查 / 多轮循环
工具执行生产目录快照 + 超时/格式/权限故障
增强配置SFT 与 RL 覆盖相同变化范围
➜
STAGE 3

HSA-RL

  • 在增强 Harness 环境中做强化学习
  • 提升对不断变化 Harness 的鲁棒性
  • 部署后遇到未见 Harness 配置仍可适应

大模型太慢，小模型过拟合

HAT 让小模型在延迟达标（3.4s P50）的同时获得大模型级 Harness 适应力，这是业务可行的关键。

随机化≠乱扰动

全部变换任务语义不变、数值约束在业务合法范围内，避免模型学到错误世界。

通用能力要显式保护

Stage 2 用通用 on-policy 蒸馏专门修复 SFT 的通用能力退化，三阶段缺一不可。
