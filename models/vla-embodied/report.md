## 0. 摘要（TL;DR）

**如果说「世界模型」回答的是 AI 能否在脑中**预测**物理世界的下一状态，那么「视觉-语言-动作模型（Vision-Language-Action，VLA）」回答的就是更直接的一问：AI 能否**输出动作**、真正动手改变物理世界。** 2025 年末到 2026 年，随着人形机器人走出实验室、通用操作策略在叠衣 / 整屋清扫 / 双臂装配上接连跑通，VLA 已成为大模型走出数字世界、兑现物理价值的**主接口**，也是智源《2026 十大 AI 技术趋势》中「具身智能进入工业场景」「世界模型 / NSP」两条主线的交汇点 [45]。

本报告与知识库中已有的《世界模型》报告形成姊妹篇：世界模型学的是条件分布 `P(s′|s,a)`（预测），VLA 学的是策略 `π(a|o,l)`（行动）；二者正在 2026 年走向「世界-动作模型（World Action Model）」的融合。

本报告的核心判断：

1. **VLA 的本质是「把互联网规模的视觉-语言预训练，接到一个高频连续动作生成器上」。** 形式化地，一个 VLA 策略学习 `πθ(a | o_vis, l, q)`：输入图像 `o_vis`、语言指令 `l`、本体状态 `q`，输出机器人可执行的连续动作 `a`（多为末端执行器 6/7-DoF 位姿增量或关节目标）。它与普通 VLM 的唯一但关键的差别，在于多了一个**动作头（action head）**——而「如何把 VLM 的隐状态变成连续、平滑、高频的动作」正是过去三年全部技术演进的主战场 [7][20][22]。

2. **技术谱系已走过四代：** ① **语言落地**（SayCan、Code as Policies、VoxPoser，LLM 只做高层规划 / 打分，不碰连续控制）[1][3][4]；② **端到端 VLA 诞生**（RT-1 大规模真机 Transformer → RT-2 把动作编码成 token，语言知识首次直接迁移到控制）[6][7]；③ **动作表示革命 + 数据缩放**（ACT / Diffusion Policy 引入动作块与扩散，Open X-Embodiment / DROID 汇聚跨本体数据，OpenVLA 提供 7B 开源基线）[8][9][12][14][20]；④ **生成式动作头与通用人形**（π0 / π0.5 的流匹配、Gemini Robotics 的 VLA+ER 双模型、NVIDIA GR00T 的双系统人形基座，2026 年国产开源 VLA 密集爆发）[22][25][29][30]。

3. **三条最关键的工程主线是：动作表示、控制频率、跨本体泛化。**
   - **动作表示**在「离散 token（好复用 LLM 栈）↔ 连续向量（精度高、延迟低）」光谱上演化；FAST 用 DCT 分词把离散路线的吞吐大幅拉高，扩散 / 流匹配则成为连续路线的主流 [9][21][23][24]。
   - **控制频率**靠「动作块（Action Chunking）+ 异步推理（感知与动作解耦）」把闭环执行推到 50–300Hz，解决「大脑想得慢、身体要动得快」的矛盾 [8][26]。
   - **跨本体泛化**靠统一动作空间、本体条件化 token 与跨本体注意力，让一个模型驾驭单臂 / 双臂 / 移动操作 / 人形等多种构型 [12][31]。

4. **「双系统 / 分层」成为旗舰系统的共同架构选择。** GR00T N1 显式采用 System 2（VLM，低频语义理解与子目标）+ System 1（扩散 Transformer，高频流畅动作）并端到端联合训练 [30]；π0.5 用高层语义子任务预测条件化低层动作 [25]；Figure 的 Helix 用「慢系统 + 快系统」双 VLA 在本机实时运行 [47]。这与认知科学的 System 1/2 类比高度一致，本质是**用低频大模型保证泛化、用高频小模型保证实时与平滑**。

5. **真正的瓶颈不是模型，而是数据与评测。** 真机遥操作数据昂贵，业界用「真机演示 + 人类第一视角视频 + 仿真 / 世界模型合成」三燃料共训，并探索「灵巧性缩放定律」（NVIDIA 称 GR00T N1.7 用 2 万+小时人类视频，**厂商口径**）[30][48]。而评测上，**开环动作误差、仿真基准分数与真机闭环成功率长期脱钩**，LIBERO / CALVIN / SimplerEnv 各有适用边界，真机成功率才是金标准 [39][40][41]。2026 年最活跃的前沿是 **VLA × RL × 世界模型**的三位一体——用世界模型想象数据、用闭环成功率做 RL 奖励，超越纯模仿学习。

## 1. 为什么是现在：从「预测下一个词」到「输出下一个动作」

### 1.1 什么是 VLA：一个会「动手」的多模态大模型

机器人策略本身并不新鲜：给定观测输出动作的 `π(a|o)` 是强化学习与模仿学习研究了几十年的对象。VLA 的新意在于**骨干换成了在互联网图文 / 视频上预训练的视觉-语言模型（VLM）**，从而把网络规模的语义先验带进了控制系统：

```
            ┌─────────────── 预训练（互联网规模）──────────────┐
图像 o_vis ──▶ 视觉编码器 (DINOv2 / SigLIP / Gemini ...)          │
语言指令 l ──▶ 文本编码器 (Llama / PaliGemma / ...)   ──▶ VLM 骨干 ──▶ 隐状态 h
本体状态 q ──▶（关节角 / 夹爪 / 里程计，作为额外 token）            │
            └───────────────────────────────────────────────┘
                                                              │
                                              h ──▶ 动作头 ──▶ 连续动作 a
                                                  (AR / 扩散 / 流匹配 / 回归)
        机器人执行 a ──▶ 环境产生新观测 o′ ──▶ 闭环（50–300 Hz）
```

形式化地，VLA 学习条件策略 `πθ(a_t | o_vis,≤t, l, q_≤t)`，动作空间通常是末端执行器位姿增量（xyz + 四元数 / 欧拉角 + 夹爪，约 7 维）或关节目标，一次输出一个**动作块** `a_{t:t+H}` 而非单步 [8][20][22]。

它与三类近邻概念的边界值得厘清：

| 概念 | 学什么 | 输出 | 典型代表 |
|---|---|---|---|
| **VLM / VLA 中的「大脑」** | 图文对齐、语义理解 | 文本 / 框 / 路点 | PaliGemma、Qwen-VL |
| **世界模型** | `P(s′|s,a)` 预测下一状态 | 未来观测 / 隐状态 | Genie、V-JEPA、Dreamer（见姊妹报告） |
| **VLA（本报告）** | `π(a|o,l)` 策略 | **可执行连续动作** | RT-2、OpenVLA、π0、GR00T |

### 1.2 与世界模型的分工：预测世界 vs 改变世界

知识库已有《世界模型》报告详述 NSP（Next-State Prediction）范式。二者关系不是竞争而是**条件分布的互补**：

- 世界模型回答「**如果我这样做，会发生什么**」——擅长反事实想象、规划、造合成数据；
- VLA 回答「**我现在该怎么做**」——擅长把语义意图翻译成实时电机动作。

2025 年起两者加速融合：GR-2 直接用生成式视频预测来产生动作 [28]；DreamGen 用视频世界模型为策略学习生成数据 [37]；到 2026 年，arXiv 上已出现明确以「World Action Model」「一步去噪世界动作模型」为名的工作（如 DIDO，2026），把「预测」与「动作」收进同一个生成模型。智源把「世界模型」列 2026 十大趋势之首、「具身智能工业出清」列第二，本质上是同一枚硬币的两面 [45]。

### 1.3 为什么在 2025–2026 爆发：三燃料、双系统、硬件成熟

VLA 并非 2026 年才出现（RT-2 在 2023 年中），但它在近两年从「实验室 demo」走向「准工业能力」，是三股力量叠加的结果：

1. **数据燃料齐备**：Open X-Embodiment 汇聚 22 种本体、超百万条轨迹 [12]；DROID 提供 76k 条「在野」分布式真机数据 [14]；AgiBot World、RoboMIND 等国产大规模真机数据集跟进 [17][18]；人类第一视角视频与仿真 / 世界模型合成数据补足长尾 [37]。
2. **架构收敛到「VLM 大脑 + 高频动作专家」的双系统**，化解了「大模型推理慢」与「机器人控制需要毫秒级响应」的根本矛盾 [25][30]。
3. **硬件与供应链成熟**：人形机器人（特斯拉 Optimus、宇树、优必选等）和低成本双臂遥操作平台（ALOHA 系列 [8][15]）把数据采集与真机验证的成本大幅拉低；端侧芯片开始跑得动轻量化 VLA [26]。

## 2. 思想源流：四步走完「从语言到动作」

### 2.1 第一代 · 语言落地（2022）：LLM 只当「嘴」和「脑」，不当「手」

最早把大语言模型用于机器人的工作都**回避了连续控制**：

- **SayCan（2022-04，Google）**[1]：LLM 根据指令给出候选高层技能（skill）的语言概率（"Say"，语义可行性），再由一个价值函数估计每个技能在当前状态下的可供性（"Can"，物理可行性），两者相乘选动作。LLM 完全不输出电机指令。
- **Inner Monologue（2022-07）**[2]：把任务成功检测、物体检测、场景描述、触觉等反馈当作「内心独白」回灌给 LLM，实现闭环重规划。
- **Code as Policies（2022-09）**[3]：让 LLM 直接生成调用感知 / 控制原语的**代码**，把语言模型变成「组合性策略程序」的编写器。
- **VoxPoser（2023-07）**[4]：LLM 生成 3D 价值地图（affordance / 约束地图），再由经典运动规划器执行，擅长「把打开的抽屉推回去」这类组合泛化。

这一代的共同结构是 **「LLM 高层规划 + 独立的传统控制器 / 小策略底层执行」** 的分层管道。优点是无需机器人数据即可获得开放词汇泛化；致命缺点是**模块化误差累积、缺乏端到端反应速度、无法处理需要连续精细控制的接触密集任务**。

### 2.2 第二代 · 端到端 VLA 诞生（2022–2023）：RT-1 与 RT-2

**RT-1（2022-12）**[6] 用 13 万条真机演示训练一个纯 Transformer 策略：图像 + 自然语言指令经 Tokenization 后自回归输出离散化的臂部动作（11 维：基座位移、7 臂自由度、夹爪等，各维分桶）。它第一次在真实厨房环境证明「一个网络、大量数据、直接吃图像语言出动作」可以规模化且对干扰物 / 背景有鲁棒性，但它本身不含互联网语义先验。

**RT-2（2023-07）**[7] 完成了关键一跃：把机器人动作也表示成文本一样的 **token**，直接在大规模 VLM（PaLI-X / PaLM-E 骨干）上**共训**互联网图文数据与机器人数据。于是「拿起被遗忘的玩具」这类训练中从未见过的物体 / 概念，可以借助 VLM 的网络知识直接泛化（涌现的视觉语义泛化）。RT-2 由此确立了 VLA 的经典范式：**互联网 VLM 预训练 → 机器人数据共训 / 微调 → 动作以 token 形式自回归输出**。

同期两条支线深刻影响了后来的工程：

- **动作块与低成本硬件（ACT / Mobile ALOHA，2023）**[8][15]：ACT（Action Chunking with Transformers）通过 CVAE 一次预测一段动作块（而非单步），显著减少复合误差、缓解分布漂移，配合时序集成（temporal ensembling）让动作更平滑；ALOHA / Mobile ALOHA 用两台千元级主从臂把双臂移动操作的数据采集成本拉到家用可负担水平，成为学术界事实标准平台。
- **扩散策略（Diffusion Policy，2023-03）**[9]：把动作生成建模为条件去噪过程，天然适合「同一观测对应多种合理动作」的多模态分布（例如绕过左 / 右障碍都行），在多套操控任务上显著优于显式 MSE / L1 回归与离散化。它开启了「连续生成式动作头」这条与 RT-2 离散 token 平行的主线。

### 2.3 第三代 · 数据缩放与开源基线（2023–2024）

VLA 要泛化，瓶颈迅速从算法转到数据。这一阶段的主线是**跨本体数据汇聚 + 开源通用策略**：

- **Open X-Embodiment / RT-X（2023-10）**[12]：由 21 家机构、22 种机器人本体联合贡献超 100 万条真机轨迹，统一到 RLDS 数据格式与标准化动作空间，并训练 RT-1-X / RT-2-X。核心实证结论是**跨本体共训带来正迁移**：在多种机器人数据上联合训练，比单本体训练效果更好——「机器人领域的 ImageNet 时刻」。
- **MimicGen（2023-10）**[16]：用少量人类演示自动生成大量跨物体 / 本体的仿真演示，把多任务数据成本压低 1–2 个数量级。
- **DROID（2024-03）**[14]：分布式采集的 76k 条「在野」操控演示，场景、本体、操作者高度多样，并带细粒度语言标注。
- **Octo（2024-05）**[19]：开源通用机器人策略，采用扩散动作头 + 灵活的输入输出适配，可微调到不同机械臂与传感器。
- **OpenVLA（2024-06）**[20]：7B 参数开源 VLA（Llama 2 语言模型 + 融合 DINOv2 与 SigLIP 的视觉编码器），在 **970k 条 Open X 真机演示**上训练。论文报告其在泛化操控上比闭源的 RT-2-X（55B）绝对成功率高 16.5 个百分点以上，并提供了成熟的微调路径，迅速成为学术界与产业界最广泛复用的开源底座。
- **HumanPlus（2024-06）**[13]：用「人形影子」方式从人类运动中学习双手操作，为类人本体的数据采集提供新范式。

这一阶段还出现了两个影响深远的设计取向：**统一 / 异构本体建模**（HPT，2024-09）[31] 用共享的「主干 Transformer + 各本体的小型 stem/tokenizer」把视觉、本体感知等异构模态映射到统一潜空间，一套主干可驱动多种本体；以及空间智能（SpatialVLA，2025-01）[27] 显式引入深度 / 点云 / 特征匹配等空间表示，显著提升需要几何理解的操作。

### 2.4 第四代 · 生成式动作头、双系统与通用人形（2024-10 至今）

2024 年 10 月起，旗舰系统集体转向**连续生成式动作头 + VLM 骨干 + 双系统分层**，并把目标从桌面单臂推向双臂、移动操作与人形：

- **π0（2024-10，Physical Intelligence）**[22]：在预训练 VLM 上叠加一个**流匹配（flow matching）动作专家**，在单臂、双臂、移动操作等多种灵巧平台的大规模异构数据上训练。流匹配学习从噪声到动作块的连续流，少量采样步即可生成高频、平滑动作，兼顾了扩散的多模态能力与自回归的速度；高层可由另一个 VLM 下发语言子指令。
- **RDT-1B（2024-10）**[21]：10 亿参数的双臂扩散基础模型，在大规模双臂数据上预训练，主打双臂协同操控。
- **GR-2（2024-10，字节）**[28]：生成式视频-语言-动作模型，用视频预测的方式把网络规模知识用于操控，是「世界模型 × 动作」的早期代表。
- **Gemini Robotics（2025-03，Google DeepMind）**[29]：基于 Gemini 2.0 构建的模型族，包含两个模型——**Gemini Robotics**（直接控制机器人的 VLA）与 **Gemini Robotics-ER（Embodied Reasoning，具身推理模型）**，后者增强空间 / 时间理解，可做检测、指向、轨迹与抓取预测、多视角对应与 3D 框预测；VLA 建立在 ER 之上。报告给出「100 条演示学习新短程任务」「适配全新本体」等能力（厂商口径）。
- **GR00T N1（2025-03，NVIDIA）**[30]：面向通用人形机器人的开放基础模型，显式的**双系统架构**——System 2 视觉-语言模块理解环境与指令，System 1 扩散 Transformer 实时生成流畅电机动作，二者紧耦合、端到端联合训练；训练数据混合真机轨迹、人类视频与合成数据。
- **π0.5（2025-04）**[25]：在 π0 基础上通过异构任务**共训**（多本体数据 + 高层语义预测 + 网络数据），首次让端到端学习系统在真实家庭中完成**清扫整间厨房 / 卧室**这类长程灵巧操作，主打开放世界泛化。
- **OpenVLA-OFT（2025-02）**[24]：系统研究 VLA 微调中的解码方式、动作表示与损失，提出「并行解码 + 动作块 + 连续动作表示 + 简单 L1 回归」的优化微调配方，在 LIBERO 上刷新纪录，并大幅提升推理效率——说明**后训练配方与架构同等重要**。
- **FAST（2025-01）**[23]：用 DCT（离散余弦变换）对动作块做高效分词，把一整段动作压缩成少量 token，使自回归 VLA 的动作吞吐大幅提升，让离散路线重新具备高频竞争力。
- **SmolVLA（2025-06，Hugging Face）**[26]：社区数据驱动的小模型，单 GPU 可训练、消费级 GPU 甚至 CPU 可部署，并引入「感知 / 动作预测与执行解耦」的异步推理栈，代表了**端侧普惠**路线。
- **智源 RoboBrain 系列**[32][33][34]：RoboBrain v1（2025-01）提出从抽象到具体的统一操作脑模型；RoboBrain 2.0（2025-07）、RoboBrain 2.5（2026-01，主打「深度在眼、时序在心」）持续迭代，是国产具身大脑的代表。
- **Figure Helix（2025）**[47]：Figure 公司的双系统 VLA，慢系统做语义理解、快系统（据称 200Hz 级，**厂商口径**）做人形全身控制，模型在机器人本机运行以降低延迟。

## 3. 核心技术深潜：动作表示、生成头、双系统与数据

### 3.1 动作表示：离散 token 与连续向量的光谱

「如何表示动作」看似细节，实则决定了整个系统的精度、频率、可复用工具链与训练稳定性。可沿一条光谱理解：

| 表示 | 做法 | 优势 | 劣势 | 代表 |
|---|---|---|---|---|
| **离散分桶 token** | 每个动作维度量化到 bin，当文本 token 自回归 | 直接复用 LLM 采样 / KV cache / 推理栈，语义对齐好 | 量化误差；逐 token 串行慢；高频受限 | RT-1 [6]、RT-2 [7]、OpenVLA [20] |
| **压缩离散 token** | 对动作块做 DCT 等变换后再分词，一段动作=少量 token | 保留离散栈优势，吞吐与时间一致性大增 | 仍有量化；依赖分词器质量 | FAST [23]、TOAST [38] |
| **连续扩散** | 对动作块迭代去噪 | 天然多模态、输出平滑、接触任务强 | 多步去噪延迟高 | Diffusion Policy [9]、RDT-1B [21]、GR00T System1 [30] |
| **连续流匹配** | 学噪声→动作的连续流，少步采样 | 快、灵巧、高频，兼顾多模态 | 训练 / 工程较新 | π0 / π0.5 [22][25]、Gemini Robotics [29] |
| **连续回归** | 直接并行回归动作块（L1） | 实现最简单、并行、延迟低 | 单峰假设，多模态动作可能平均化 | OpenVLA-OFT [24]、ACT [8] |

两个横切设计几乎成为标配：

- **动作块（Action Chunking）**[8]：一次预测未来 H 步而非一步，用预测视界换取时间一致性、减少复合误差；再配合时序集成（重叠块加权平均）消除块间抖动。
- **并行 vs 串行解码**[24]：OpenVLA-OFT 发现，把动作 token 改为并行预测（而非逐个自回归）+ 连续表示 + L1 损失，能同时提升速度与成功率——这是「后训练工程」反超「架构叙事」的典型案例。

### 3.2 三类动作生成头：自回归、扩散、流匹配

- **自回归头（AR）**：策略就是一个语言模型，动作 token 接在图文 token 后逐个生成。优点是与 VLM 无缝、天然条件化、可复用全部 LLM 基础设施；缺点是串行延迟与误差累积。FAST 类高效分词 [23] 与并行解码 [24] 是主要缓解手段。
- **扩散头（Diffusion）**：把动作块当作以观测 / 语言为条件的去噪目标，推理时从高斯噪声迭代去噪。其核心红利是**多模态建模**——当任务存在多种等价动作时，扩散不会像 MSE 那样回归到「平均动作」（往往是不可执行的折中）。代价是多步采样的延迟，工程上通过减少去噪步、动作块缓存与异步执行弥补。
- **流匹配头（Flow）**：π0 的关键创新 [22]。它训练一个连续归一化流 / 向量场，把简单噪声分布直线「搬运」到动作分布；相比扩散，流匹配的路径更直、可用更少的积分步采样，因此更适合高频闭环。π0 把它作为一个**独立的动作专家模块挂接在冻结 / 轻训的 VLM 骨干上**，既保留语义先验又获得连续控制能力。

### 3.3 双系统 / 分层架构：让「慢大脑」驱动「快身体」

机器人闭环控制通常要求 50Hz 以上（接触 / 人形往往要 200–300Hz），而大型 VLM 的推理频率只有几 Hz 到十几 Hz。双系统架构是对这一矛盾的系统性回答：

```
图像/语言/本体 ──▶ System 2（VLM 慢系统，~1–10Hz）
                    │  输出：语言子目标 / 语义路点 / 检测框 / 隐状态条件
                    ▼
                 System 1（动作专家快系统，50–300Hz）
                    │  扩散 / 流匹配 / 回归，输出动作块
                    ▼
                  机器人执行 ──▶ 新观测（快回路可不等 System2）
```

- **GR00T N1** 明确把视觉-语言模块（System 2）与扩散 Transformer（System 1）分开但端到端联合训练 [30]；
- **π0.5** 通过「高层语义子任务预测 + 低层动作」的异构共训实现类似分工 [25]；
- **Gemini Robotics-ER → Gemini Robotics** 是「先具身推理、再具身动作」的两模型组合 [29]；
- **Figure Helix** 则把快慢两套 VLA 都部署在机器人本机，快系统据称以约 200Hz 输出全身动作（**厂商口径**）[47]。

这一架构的深层逻辑与认知科学的双过程理论（Kahneman System 1/2）同构：**用低频、参数大、泛化强的慢系统负责「想清楚做什么」，用高频、参数小、反应稳的快系统负责「平滑地做出来」**。它也自然解耦了部署——慢系统可上云 / 用大模型，快系统必须端侧。

### 3.4 数据三燃料与后训练流水线

真机遥操作数据是 VLA 最大的成本项，业界形成三类燃料混合共训的格局：

1. **真机遥操作演示**：质量最高、分布最真实，但贵。代表数据集 Open X-Embodiment（百万级轨迹 / 22 本体）[12]、DROID（76k 在野）[14]、AgiBot World Colosseo [17]、RoboMIND / RoboMIND 2.0（多本体 / 双臂移动操作）[18]、Mobile ALOHA 双臂数据 [15]。
2. **人类第一视角视频**：体量巨大但无动作标签，需要通过动作学习 / 跨域对齐才能用。NVIDIA 称 GR00T N1.7 基于 2 万+小时人类第一视角视频，并提出「灵巧性可随人类数据可预测提升」的缩放律（**厂商口径，尚待独立复现**）[48]；HumanPlus 则直接从人类运动影子示教 [13]。
3. **仿真 / 世界模型合成**：Isaac Sim、NVIDIA Cosmos 等仿真平台，MimicGen 的自动演示扩增 [16]，以及 DreamGen 等用视频世界模型生成训练数据 [37]。核心价值是覆盖长尾、危险 / 罕见场景并降低真机时长，但要持续对抗 sim2real 差距与「合成数据自蒸馏导致分布坍缩」的风险。

后训练流水线通常为：**互联网 VLM 预训练 → 跨本体机器人数据共训 / 动作头后训练 → 面向新本体 / 新任务的少量演示微调（100–150 条量级）或 RL 微调 → 量化 / 蒸馏后端侧部署**。OpenVLA-OFT 证明微调配方（并行解码、连续表示、L1）对最终性能影响巨大 [24]；SmolVLA 则用异步推理栈把小模型的实际响应做到可部署 [26]。

### 3.5 跨本体泛化：一个模型驱动多种「身体」

通用 VLA 的雄心是「一个模型驱动多种身体」，但机械臂在自由度、动作空间、相机布置、动力学上差异巨大。主流三条技术路径：

- **统一动作空间 + 本体标识**：Open X-Embodiment 把各本体数据映射到标准化的末端执行器动作表示，并在输入中加入本体 / 数据集标识，让模型学会条件化于「身体」[12]。
- **异构预训练 Transformer（HPT）**[31]：为每种本体 / 模态配一个小型 stem（tokenizer），把异构观测映射进共享潜空间，再接一个大规模共享主干，输出经各本体的 head 解码。新增本体只需训练小 stem/head，主干复用，显著提升跨本体迁移效率。
- **跨本体注意力 / 本体条件 token**：在注意力层显式注入本体描述（运动学结构、相机内外参），如产业界地平线 HoloBrain-0 宣称把多视角相机参数与机器人运动学作为「具身先验」显式注入（**厂商口径**）[49]。

跨本体能力的实证信号包括：π0.5 / Gemini Robotics 报告可适配全新本体、用少量演示学习新任务 [25][29]；国产 LingBot-VLA 称基于 9 种双臂机器人 2 万小时数据、150 条示教即可适配新机型（**厂商口径**）[49]。但需强调，这些多为厂商自报，跨本体泛化的**鲁棒边界与负迁移条件**仍是开放研究问题。

## 5. 评测：为什么「仿真高分」不等于「真机好用」

VLA 评测是出了名的困难，也是厂商宣传最容易「注水」的环节。理解评测体系，才能理性看待各种「SOTA / 全球第一」。

### 5.1 三层评测体系

- **仿真操作基准**：成本低、可重复。**LIBERO** [39] 包含终身学习、空间、任务、物体四个套件，考察知识迁移与泛化，是当前最常用的 VLA 刷榜基准；**CALVIN** [40] 在长程语言条件操作上评测，要求连续完成多个子任务。
- **在仿真中评测真机策略（SimplerEnv）**[41]：把真实训练的策略放进经过校准的仿真场景评估，以远低于真机的成本估计真实世界表现，是连接仿真与真机的重要折中。
- **真机 / 平台基准**：金标准但昂贵、难复现。Open X 跨本体评测 [12]、RoboMIND [18]、产业平台 RoboChallenge（千寻 Spirit 称首个击败 π0.5 基线、成功率超 50%，**厂商口径**）等 [49]。

### 5.2 四个方法论陷阱

1. **开环损失与闭环成功率弱相关**：动作 MSE / L1 误差低，不代表闭环任务成功率高——机器人可以通过反馈修正小误差，也可能被一个关键错误动作彻底毁掉。评测必须以**闭环任务成功率**为准。
2. **仿真到真机的 domain gap**：LIBERO / CALVIN 高分可能在真机上崩塌；接触动力学、摩擦、反光、柔性物体尤其难仿真。
3. **横评不可比**：不同工作使用的任务子集、本体、提示词模板、图像分辨率、动作空间不一致，直接比百分比常具误导性；需关注是否在同一协议下评测。
4. **平均成功率掩盖长尾**：OOD 物体、干扰物、长程任务的失败被平均值稀释。严谨的报告会给出成功率方差、逐条任务结果与失败模式分类。

> 实践含义：看到「9 项基准全球第一」「超越 π0.5」这类说法时，应追问：**是仿真还是真机？哪个版本的基准 / 本体？是否同协议？有没有第三方复现？** 国产系统的多数榜单数据目前仍是厂商口径 [49]。

## 6. 六大开放问题与 2026 前沿战场

### 6.1 数据效率与「灵巧性缩放定律」

真机数据昂贵是第一矛盾。核心悬念是：**无需动作标签的人类视频，究竟能在多大程度上稳定转化为机器人能力？** NVIDIA 为 GR00T N1.7 提出「灵巧性缩放定律」——更多人类第一视角数据可直接、可预测地提升灵巧性而无需大规模遥操作（**厂商口径**）[48]。若成立，将把 VLA 的数据成本结构彻底改写；但学界普遍警惕合成 / 网页数据自蒸馏导致的「模型坍缩」与分布窄化，需要独立复现。相关方向还包括用世界模型（DreamGen [37]、Cosmos）造数据、用 MimicGen [16] 扩增仿真演示。

### 6.2 跨本体 / 跨形态泛化

从单臂到双臂、移动操作、人形、灵巧手，自由度与动力学差异巨大。HPT 的异构主干 [31]、统一动作空间 [12]、本体条件化是当前主路，但「少量演示（100–150 条）适配新本体」的适用边界、何时出现负迁移、手部 / 手指级精细控制（GR00T N1.7 主打手指级控制 [48]）仍未解决。

### 6.3 长程任务、错误恢复与记忆

整屋清扫这类任务需要数十步连贯执行、子目标分解与中途纠错。π0.5 用高层语义子任务预测首次端到端跑通 [25]，但成功率、对意外的恢复能力、跨回合的长期记忆仍不稳定。这天然连接知识库已覆盖的两个方向：**Agent Memory**（跨会话 / 跨回合的情景与程序记忆）与**世界模型**（想象未来、做长程规划）。RoboOS 等分层具身框架也在探索跨本体多智能体协作 [35]。

### 6.4 推理效率与端侧部署

人形机器人对端到端延迟极其敏感。技术手段包括：轻量化模型（SmolVLA [26]、优必选 Thinker 4B、地平线 0.2B/1.1B 等**厂商口径**[49]）、动作头去噪步数压缩、并行 / 异步推理（感知与动作解耦，执行不等推理）[26]、量化（VLAQuantBench、ActQuant 等 2026 新工作关注 VLA 量化的闭环评测）。值得注意的是，**降低延迟会改变闭环行为本身**——更快的部署可能带来与离线评测不同的成功率，需专门的成功-延迟联合分析。

### 6.5 安全、可信与可解释

VLA 直接驱动物理硬件，错误代价远高于文本错误。前沿关注：运行时监控与越界拒动（runtime assurance）、动作的可证书化 / 形式化保证、对抗性数据投毒（开源权重 + 社区数据带来的供应链风险，已有研究演示针对 SmolVLA 的投毒攻击）、人机协作安全水位。这与智源 2026 趋势第 10 条「从幻觉到欺骗、机制可解释与自演化攻防」相呼应 [45]。

### 6.6 VLA × RL × 世界模型：超越纯模仿

模仿学习（行为克隆）受限于演示质量、存在分布漂移，且只会「模仿演示里的成功」。2026 年最激动人心的方向是三者融合：**用世界模型想象未来 / 生成反事实数据，用闭环任务成功（或可验证奖励）做强化学习，再回灌改进策略**。arXiv 2026 年已出现「世界批评模型（World Critic Model）指导 VLA 强化学习」「一步去噪世界动作模型（DIDO）」「动作忠实的世界模型反事实后训练（DreamTrue）」等大量工作，标志着 VLA 正从「模仿的策略」走向「会想象、能试错、可自我改进的策略」。这也与知识库已覆盖的 **Agentic RL**（多轮环境、轨迹级奖励、稀疏奖励）方法论深度合流。

## 7. 产业格局：2025–2026 的「VLA 军备竞赛」

### 7.1 海外：旗舰闭源 + 开放平台双线

- **Physical Intelligence（π 系列）**：以流匹配动作专家和整屋级长程操作树立学术与工程双重标杆，π0 / π0.5 是被对标最多的闭源前沿，FAST 则把动作分词工具链开放给社区 [22][23][25]。
- **Google DeepMind（Gemini Robotics / ER）**：把最强多模态推理（Gemini 2.0）延伸为「具身推理 + 具身动作」模型族，强调空间 / 时间理解与跨本体适配，是「大模型公司亲自下场做机器人」的标志 [29]。
- **NVIDIA（GR00T + Isaac/Cosmos）**：走「开放人形基座模型 + 仿真合成数据 + 全栈开发平台」路线，GR00T N1 双系统、N1.7 动作级联与手指级控制，配合 Isaac Sim / Cosmos 与 GPU 生态，卡位「机器人时代的算力与平台层」[30][48]。
- **Figure（Helix）等本体厂商**：垂直整合「模型 + 人形本体」，主打本机实时双系统控制与商业化场景落地，Helix 的快慢系统把端侧实时性做到极致（频率为厂商口径）[47]。
- **开源学术生态**：Stanford / Berkeley 等贡献 OpenVLA、Mobile ALOHA、Octo、HPT、Open X-Embodiment，Hugging Face 推出 SmolVLA，构成中小团队可负担的事实工具链 [12][15][19][20][26][31]。

### 7.3 生态位判断

- **上游（模型 / 算力 / 仿真）**：Google、NVIDIA、Physical Intelligence 与开源 VLM 骨干（Llama / Qwen）主导；
- **中游（通用 VLA 与数据平台）**：Open X / DROID / AgiBot / RoboMIND 等数据集 + OpenVLA / GR00T / 国产开源基座竞争；
- **下游（本体与场景）**：人形 / 双臂 / 移动操作厂商垂直整合，工业装配、物流、家用服务是首批落地场景。

## 8. 工程落地建议（选型 Checklist）

对于希望在真实机器人上采用 VLA 的团队，按约束选型：

1. **先定频率与硬件，再选动作头。** 高动态 / 接触密集 / 人形（需 100–300Hz）优先流匹配 / 扩散 + 动作块 + 异步推理（π 系 / GR00T 思路）[22][30]；桌面低速任务用 OpenVLA-OFT 的并行连续回归即可，简单且稳 [24]。
2. **骨干用开源 VLM，别从零训。** 7B 级（Llama/PaliGemma/Qwen-VL）是性价比甜点；资源受限用 SmolVLA 类小模型 + 量化，先验证闭环再谈放大 [20][26]。
3. **数据上「先开源共训、后少量真机微调」。** 用 Open X / DROID 类数据做跨本体预训练，再采 100–1000 条本任务真机演示微调；长尾 / 危险场景用仿真（MimicGen / Isaac / Cosmos）补充，并做严格 sim2real 抽检 [12][14][16]。
4. **务必建真机闭环评测。** 不要只看 LIBERO / CALVIN 分数；固定任务集、报告成功率方差与失败模式，用 SimplerEnv 做低成本回归测试 [39][40][41]。
5. **双系统解耦部署。** 慢系统（语义 / 子目标）可上大模型甚至云端，快系统（动作）必须端侧、带动作块缓存与超时安全策略 [26][30][47]。
6. **安全默认开启。** 运行时监控、工作空间约束、力 / 速度限位、异常即停；使用开源权重与社区数据集时排查投毒与异常轨迹。
7. **为「VLA × RL × 世界模型」预留演进路径。** 架构上保留可接入闭环奖励与世界模型想象数据的接口，避免把策略锁死在纯行为克隆 [37]。

## 9. 结论

VLA 是大模型范式向物理世界的自然延伸：**当「预测下一个词」的引擎接上「输出下一个动作」的头，AI 才真正具备了改变世界而非仅描述世界的能力。** 三年间，它走完了「LLM 当规划器（SayCan）→ 动作即 token（RT-2）→ 数据缩放与开源基线（Open X / OpenVLA）→ 流匹配 / 双系统通用人形（π0.5 / Gemini Robotics / GR00T）」四代演进。

往前看，模型架构的秘密正在快速商品化——真正稀缺的是**大规模高质量真机 + 人类视频 + 合成数据的闭环飞轮、跨本体快速适配能力、端侧实时推理，以及可信的真机评测**。2026 年最值得关注的，不是某个单点跑分，而是三条融合主线：**VLA 与世界模型融合**（会想象的动作模型）、**与强化学习融合**（用闭环成功自我改进）、**与记忆 / 多智能体融合**（长程、协作、终身学习的机器人大脑）。谁能把这三者在真实硬件上稳定闭环，谁才可能拿到「物理世界基础模型」的入场券。

> 与知识库姊妹报告联动：世界模型（预测 `P(s′|s,a)`）、Agentic RL（多轮环境的轨迹级强化学习）、智能体记忆（跨回合终身学习）共同构成「物理世界具身智能」的完整拼图，本报告聚焦其中的**动作策略 π(a|o,l)** 一环。
