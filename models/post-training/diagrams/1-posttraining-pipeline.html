Post-Training 范式流水线：从基座模型到助手模型

PRE-TRAINING → SFT → PREFERENCE ALIGNMENT / RLVR → ASSISTANT MODEL · 闭环数据迭代

地基：SFT

  • • 一切后训练的入口，冷启动可读性
  • • 少量高质量数据优于大量普通数据
  • • 只在 response token 上计损失

两条对齐路线

  • • RLHF(PPO) 效果好但贵、不稳
  • • DPO 家族去 RM，性价比高
  • • RLAIF / CAI 用原则+AI 扩规模

推理时代

  • • RLVR 规则奖励，避免 RM 失真
  • • GRPO 去 Critic，组相对优势
  • • R1 范式：冷启动→RL→蒸馏
