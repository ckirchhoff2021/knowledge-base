Anthropomorphic Agent Architecture

拟人化 Agent 六层架构：从感知层到人格内核 · Six layers from perception to persona core

拟人不是装可爱

  • • 核心不在"语气萌"，而在"被理解感"
  • • 心智推理层（L2）识别用户没说出口的需求
  • • 多层记忆（L3）让每次对话不是冷启动
  • • 人格内核（L4）保证跨时间一致性

人格是架构不是 prompt

  • • 单靠 system prompt 做不出稳定人格
  • • 身份/性格/价值观/情绪/关系需独立建模
  • • 记忆整合与反思是"成长感"的关键
  • • 主动性（proactivity）区分工具与伙伴

安全贯穿而非附加

  • • 透明度：用户必须知道在和 AI 对话
  • • 边界：拒绝情感操纵与过度依赖
  • • 内容安全在每一层都做 guardrail
  • • 合规：EU AI Act / 中国《生成式 AI 办法》
