核心矛盾

训练时为了快/稳，剥离真实脚手架；部署时装回去，模型面对全新观测分布 → 性能腰斩（ClawEval 48.5→20.9）

演进方向

从「训简推繁」→「训推一体」：在真正运行的Harness中做RL，把Prompt/工具/重试/超时都当作环境的一部分

代价

Harness-RL rollout慢、调试难、基础设施要求高（异步/多进程/中间件拦截），但收益是可直接迁移部署
