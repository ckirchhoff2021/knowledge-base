Claude Tag 运行时架构：Channel Session 执行流程（五步）

三个系统协作：Slack 工作区（请求）· Anthropic 沙盒（执行）· 外部系统（GitHub/数仓）—— Agent Proxy 是安全边界

沙盒执行

  • • Claude 在 Anthropic 侧隔离环境干活
  • • 不在客户网络安装任何东西
  • • 读文件/写文档/跑代码都在沙箱内

凭据隔离（核心安全设计）

  • • 凭据从不进入沙箱
  • • 只在出站 Agent Proxy 处注入
  • • 沙箱被攻破也拿不到凭据

三接口解耦

  • • Session 事件日志 / Harness 大脑 / Sandbox 双手
  • • container 死 ≠ session 死，可恢复续跑
  • • p50 TTFT ↓60%，p95 ↓90%+
