Claude Tag 技术栈：八层架构与算法密度标注

自下而上八层 · 算法密度：低=成熟工程 · 中=有优化空间 · 极高=开放研究问题（决定产品上限）

算法密度极高的三层

  • • L4 记忆：蒸馏/检索/遗忘全开放
  • • L5 检索：状态有效性过滤无方案
  • • L7 规划：长程漂移与敷衍交付

已趋同成熟的部分

  • • L1-L3 接入/编排/沙箱：开源两周可复刻
  • • 三接口解耦是架构精髓（TTFT -60%）
  • • 凭据隔离是安全信任根

核心判断

  • • 形态可复刻，上限由算法决定
  • • 壁垒在组织记忆的质量而非存在
  • • 三个难题都需要"对时间的推理"
